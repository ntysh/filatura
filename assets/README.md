# assets

Картинки, аудио и видео клади куда-нибудь внутрь этой папки, а потом
ссылайся на них со страницы относительным путем. Можешь создавать подпапки если удобно.

Остальное относится к интерфейсу машины, так что, скорее всего, трогать это не
придется:

- `gui/gui.png` — полный экран 3200 × 2400.
- `buttons/` — отдельно вырезанная картинка каждой кликабельной кнопки.
- `borders/` — обычное и нажатое состояния рамки кнопки.
- `zones.csv` — позиции кнопок на полной картинке экрана.
- `preview.png` — общий вид кнопок и их состояний.
