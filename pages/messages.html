STOLL Operating Instructions
STOLL Operating Instructions, section 2.9.5 and section 3.6.1, manual pages 2-42 / 3-45–3-46

The standard information function provides a list of the last messages and information.

When an error occurs, it is displayed in Current Messages and also stored in a daily message history. Seven daily memories are available, giving access to error messages from the last seven days. Tips associated with error messages are stored in the same way.
