Direct commands

STOLL Operating Instructions
STOLL Operating Instructions, section 2.9.5 and section 7.2, manual pages 2-42–2-43 / 7-17

The Direct Commands function opens a command-line and output window for direct commands.

A virtual keyboard can be opened in this window so that a command can be typed and confirmed. The additional function keys also provide a direct Sintral-command input that can be used without leaving the current menu or window.
