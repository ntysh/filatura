Changeable monitoring

STOLL Operating Instructions
STOLL Operating Instructions, production section 3.3 and section 4.1.15, manual pages 3-18 / 4-31

During production, the Changeable Monitoring window displays machine data and the program sequence.

For every carriage stroke it can show the current Sintral line and selected values such as cycle counters, Jacquards, stitch tension and counters. The displayed values can be selected manually or configured automatically, and additional function blocks can be activated or deactivated.
