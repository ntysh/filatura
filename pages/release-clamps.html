Release clamps

STOLL Operating Instructions
STOLL Operating Instructions, section 4.1.13, manual page 4-28

The thread clamping and cutting device holds the thread of a yarn carrier that is not currently being used for knitting.

When the yarn carrier is used again, the clamp opens after a defined number of knitting rows and releases the yarn end. The default is 19 knitting rows, and the value can be set individually for each yarn carrier in the Release Clamps window.
