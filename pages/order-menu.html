Order menu

STOLL Operating Instructions
STOLL Operating Instructions, section 3.4.1, manual pages 3-32–3-35

The Order Menu groups the different making-up sizes of an article into a list and processes them sequentially. The quantity and cycle counters are specified for each size.

An order line is processed until the number of pieces to be produced and the number already produced are equal. The machine then automatically switches to the next size and continues line by line from top to bottom.
