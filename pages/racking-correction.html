Racking correction

STOLL Operating Instructions
STOLL Operating Instructions, section 4.1.17 (CMS 530 T) and corresponding CMS 730 T section, manual pages 4-43 onward

Racking correction is used to achieve the optimum transfer position even with different stitch lengths. A correction value can be added to the racking specification.

During knitting, the machine can stop before the line containing the correction so that the optimum value can be entered. The corrections are both pattern-dependent and machine-dependent and can be saved or read back.
