Set up pattern

STOLL Operating Instructions
STOLL Operating Instructions, section 4.1.16, manual page 4-35

The Setting Up the Pattern menu is used for fine adjustment of a pattern directly at the knitting machine.

While the machine is knitting, the corresponding knitting-program data are displayed for every carriage stroke. If required, changes can be made directly through setting windows or by opening the corresponding setting menu from the selected field.
