Machine settings

STOLL Operating Instructions
STOLL Operating Instructions, sections 4.2.1, 4.2.4–4.2.5 and 7.1–7.3, manual pages 4-50 / 4-56–4-57 / 7-13–7-18

The Machine Settings window is used for machine-specific configuration and adjustment. It includes functions such as switching machine units on or off and accessing sensor, needle-bed and machine parameters.

The manual describes machine settings as including machine data, machine options, machine configuration, report data, network settings and other internal control information. These settings can be backed up and restored as machine data.
